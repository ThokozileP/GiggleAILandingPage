Runtime Metrics

Operational evidence for every clinical agent decision.

Runtime Metrics turns raw agent activity into evidence: what happened, who was involved, and whether it can be reconstructed later through Decision Replay.

Open Runtime Evidence Dashboard ↗ Request Demo

Interfaces on this page are illustrative previews, not live customer data.

What Runtime Metrics covers

Decision Replay

Step back through a specific agent run — the recommendation, the context available, and how the clinical workflow resolved.

Evidence Completeness

See whether a Decision Context Record has everything needed to reconstruct a decision, or where evidence gaps exist.

Escalation & Override Tracking

Track how often agents escalate, defer, or get overridden, and by whom — consistency signals for post-market monitoring.
