The CARC Control Console.

What's in the console

Runtime Sessions

Every live and completed session between your agent and CARC's Runtime Engine, from first connection to session close.

Agent Runs

Individual agent decisions within a session — recommendation, context, escalation, deferral, or override, in order.

Human Review

Where reviewers see flagged runs, act on escalations, and record the intervention evidence that feeds the Evidence Engine.

Decision Replay

Step back through any run to see exactly what the agent saw and did, and how the clinical workflow resolved.

Runtime Metrics

Evidence completeness, escalation and override rates, and consistency signals across agent runs, in one view.
